# 기획서 대비 개선·확장 사항

기획서(2026-09-29)를 그대로 구현하면서, 설계·검토 과정에서 더 낫다고 판단한 항목을 추가했다. 각 항목은 기획서 원칙(설명 없이 구조로 이해 · 한 페이지 한 가지 일 · 이름은 PC에만)을 지킨다.

## 흐름·기능

| # | 개선 | 이유 | 위치 |
| --- | --- | --- | --- |
| 1 | **교시 시간표(periods)** 를 설정에 추가 | 기획서 시간표는 요일·교시·반만 있어 "지금이 몇 교시인지" 판단 근거가 없었다. 워치 자동 실행·위젯 현재 수업·PC 보완 모달의 기준이 된다. | 설정 → 시간표, `config.periods` |
| 2 | **AI 없이도 동작하는 규칙 기반 초안 생성기** | API 키가 없거나 학교망에서 외부 API가 막혀도 2p가 멈추지 않는다. 문장별 근거 id 매핑·수준별 어미·글자수 맞춤을 동일하게 수행한다. AI를 켜면 같은 요청 형식으로 Claude에 전달. | `core/draft.ts`, 설정 → AI |
| 3 | **첫 실행 "샘플 데이터로 둘러보기"** | 명단·시간표를 넣기 전에 전 화면을 체험할 수 있다. 화학Ⅰ 2개 반, 단원별로 내용이 맞는 기록, 보완 대기 건, 수행평가 포함. | 온보딩, 설정 → 데이터 |
| 4 | **PC에서 직접 기록 추가** (1p [+ 기록]) | 워치·폰이 없거나 방전됐을 때의 대안. `source: "pc"`. | 1p |
| 5 | **보완 모달 단축키** Enter 저장 · Esc 닫기 · 이전/다음, 카테고리 변경 가능 | 1~2분 안에 여러 건 처리 목표에 맞춰 마우스 없이 진행. 단원·카테고리 기반 추천 문구도 1차 구현. | 보완 모달 |
| 6 | **연결 기기 자동 등록 + ping** | 폰이 QR을 스캔하면 `ping`을 보내 PC 연결 기기 목록에 뜨고, PC는 즉시 설정을 내려보낸다. 페어링 성공을 눈으로 확인할 수 있다. | 설정 → 동기화 |
| 7 | **같은 Wi-Fi 직접 전송 = 릴레이를 PC에서 실행** | 별도 프로토콜 대신 동일 릴레이 코드를 교사 PC에서 `npm run relay`로 띄우고 LAN IP를 QR에 넣는다. 서버 운영 주체·비용 미결 사항을 우회할 수 있는 선택지. | `apps/relay` |
| 8 | **폰 시뮬레이터** `tools/phone-sim.mjs` | 폰 앱 빌드 없이 프로토콜(암호화·봉투·config 수신)을 검증. 안드로이드 구현과 PC 구현이 같은 계약을 따르는지 확인하는 기준. | `tools/` |
| 9 | **검토 패널에서 즉시 수정**: 문장 삭제 · 어체 자동 고침 적용 · 무시 | 3p에서 2p로 왔다 갔다 하지 않고 대부분의 어체·금지어 문제를 그 자리에서 처리. | 3p 우측 패널 |
| 10 | **NEIS 바이트 병기** (한글 3바이트) | 미결 사항 "글자수 기준"에 대해 공백 포함/제외 전환 옵션 + NEIS 바이트를 검토 패널에 함께 표시. | 설정 → 글자수, 3p |
| 11 | **명단 붙여넣기** (번호 이름 [수준] 줄 단위) 와 학번(20315) 자동 분해 | 엑셀 양식 없이 나이스 명렬을 복사해 붙일 수 있다. | 설정 → 반·명단 |
| 12 | **초안 직접 편집 시 문장-근거 매핑 보존** | 교사가 텍스트를 손보면 문자 유사도로 기존 문장의 근거 id를 이어받아, 검토의 "근거 없는 문장" 오탐을 줄인다. | 2p |
| 13 | **학생 이름 포함 검사** (검토 규칙 추가) | 기획서 규칙 1(이름 없음)을 검토 단계에서도 자동 확인. | `core/review.ts` |
| 14 | **일괄 생성 중지 · 행별 재시도 · 진행 바** | 기획서 10.5의 "실패 시 해당 행만 재시도"에 더해 중간 중지 가능. | 2p 일괄 |
| 15 | **수행평가 OCR은 선택적 로드** (tesseract.js CDN, 실패 시 수동 발췌) | 로컬 OCR 정확도 미검증 사항에 대한 안전한 기본값: OCR이 안 되더라도 파일명(이름/학번) 매칭과 수동 발췌로 흐름이 끊기지 않는다. | 2p 수행평가 등록 |
| 16 | **위젯 → 앱 딥링크에 카테고리 사전 선택**, 수업 시작 알림에 카테고리 4개 액션 | 위젯 없이 알림만으로도 탭 2번에 기록. | 폰 앱 |

## 설계·보안

- 봉투에 **AAD = keyId** 를 넣어 다른 키 상자로 재전송된 암호문이 복호화되지 않게 했다.
- 삭제는 **tombstone** 으로 전파하고, 같은 id는 `updatedAt` 늦은 쪽 우선(기획서 13-5 그대로).
- JSON 내보내기에서 **API 키 제거**, 암호화 백업은 PBKDF2(200k) + AES-256-GCM.
- `config.roster` 는 PC에서 "폰에 이름 표시"를 켠 경우에만 채우고, 폰은 워치로 중계할 때 항상 제거한다.

| 담임 확장(행특·창체) | 데이터 모델에 `field` 로 자리만 확보 | `core/types.ts` |
