# 누가 — 소개(랜딩) 페이지

GitHub Pages 의 첫 화면(https://dacisosl.github.io/NUGA/)이다. 웹 앱은 그 아래 `app/`(https://dacisosl.github.io/NUGA/app/)에 있다.

## 구성
- index.html: 11개 화면의 내용과 구조
- site.css: 반응형 레이아웃, 색상, 글꼴, 모션 스타일
- site.js: 숫자 릴, 화면 이동, FAQ, 영상 및 마우스 반응, 앱으로 넘어가기
- assets/growth-poster.png: 계단 메인 이미지
- assets/growth-motion.mp4: 계단 빛 모션 영상
- assets/record-manual.mp4 · record-auto.mp4 (+ 포스터): '기록 방법' 두 화면의 영상. 실제 앱 화면으로 만들며, 만드는 법은 [video/README.md](video/README.md)
- assets/whale-1~4.jpg: '웨일 연계' 화면의 실제 앱 사진 4장 (`video/capture-whale.mjs`로 찍는다), assets/whale-logo.png: [웨일 연계] 버튼의 웨일 로고

## 기록 방법 화면 (6 · 7번째)
- 영상 옆 단계 01~04 가 재생 위치(`data-at` 초)에 맞춰 밝아지고, 단계를 누르면 그 장면으로 간다.
- 그 화면에 0.4초 이상 머물면 소리 없이 재생하고, 벗어나면 멈춘다. 다음 화면이 기록 방법이면 미리 받아 둔다(데이터 절약 모드에서는 받지 않는다).
- 영상 오른쪽 아래 [영상 재생 | 영상 일시정지] 버튼으로 언제든 멈추고 다시 볼 수 있다. 멈추면 그 화면에 있는 동안은 다시 재생하지 않는다.
- 움직임 줄이기 설정이거나 첫 화면의 '모션 일시정지'를 눌렀으면 자동 재생하지 않고 내려받지도 않는다. [영상 재생]이나 단계를 누르면 그때 재생한다.

## 앱으로 넘어가기
- `data-app-link` 가 붙은 링크(머리글 '앱 열기', 첫 화면 '바로 시작하기', 마지막 화면 '누가 시작하기')는 모두 앱의 전체 주소(https://dacisosl.github.io/NUGA/app/)로 간다. 상대 경로가 아니라서 index.html 을 파일로 열어도 앱으로 이어진다.
- 누르면 앱과 같은 남색(#081422)으로 0.38초 덮은 뒤 넘어간다. 앱도 같은 남색에서 시작하므로 흰 화면이 번쩍이지 않는다. 움직임 줄이기 설정이면 바로 넘어간다.
- 링크에 마우스를 올리거나 초점이 가면 앱의 JS·CSS 를 미리 받아 둔다(데이터 절약 모드에서는 받지 않는다).
- 뒤로 가기로 돌아오면 덮개를 걷는다.

## 웨일 연계 화면 (8번째)
- 기록 방법 2 바로 뒤. 앱의 웨일 모드(웨일 스페이스와 함께 쓰는 하루)를 실제 앱 사진 4장으로 보여 준다: 01 수업 중 사이드바(큰 창 + 웨일 사이드바의 모바일 화면) · 02 쉬는 시간 기록 · 03 방과 후 피드백 고리 · 04 학기 말 생기부 생성.
- 기록 방법 화면과 같은 틀(사진 | 단계 01~04). 그 화면에 있을 때만 5.2초마다 다음 사진으로 넘기고, 사진·단계 위에 마우스나 초점이 있으면 멈춘다. [자동 넘김 멈춤]으로 그 방문 동안 멈출 수 있고, 단계를 누르면 그 사진으로 간다. 움직임 줄이기 설정이면 저절로 넘기지 않는다.
- 아래 [웨일 연계 · 앱에서 둘러보기]는 앱의 웨일 모드(https://dacisosl.github.io/NUGA/app/?whale=1&from=landing)를 바로 연다(`data-app-link`). 앱 안의 둘러보기 칸 머리에 '← 소개 페이지로'가 붙는다.
- 머리글의 [웨일 연계](웨일 로고 아래 작은 글씨)는 이 화면(#whale)으로 내려간다. 폰 너비(480px 이하)에서는 머리글에 [웨일 연계]·[앱 열기]만 남긴다.
- 앱 상단 바에도 같은 모양의 [웨일 연계] 버튼이 있다. 웨일 모드는 선생님 영역과 따로 만든 데모 영역에서 돌아가고, 끝내면 원래 영역으로 돌아간다.
- 사진을 다시 찍으려면: 앱 개발 서버를 띄우고 `node apps/landing/video/capture-whale.mjs` (시계 2026-10-28(수) 10:05 고정, 처음 방문한 브라우저로 `?whale=1`에 들어가 장면을 클릭·입력으로 진행).

## 실행
빌드나 npm 설치가 필요 없다. 이 폴더에서 정적 서버를 띄운다.

    python -m http.server 8000

그다음 http://localhost:8000 에 접속한다. index.html 을 파일로 바로 열어도 된다.
앱으로 가는 버튼은 언제나 배포된 앱으로 간다.

## 배포
`.github/workflows/pages.yml` 이 main 에 푸시할 때마다 이 폴더의 index.html·site.css·site.js·assets 를 사이트 맨 위에, 데스크톱 웹 빌드(`VITE_BASE=/NUGA/app/`)를 `app/` 에 올린다.

- 문구는 index.html, 디자인은 site.css, 동작은 site.js 에서 고친다.
- 다른 주소로 배포할 때는 index.html 의 canonical 주소와 `data-app-link` 링크 세 곳의 앱 주소를 함께 바꾼다.
- Pretendard 글꼴은 외부 CDN 에서 불러온다. 연결이 없으면 기본 시스템 글꼴로 보인다.
