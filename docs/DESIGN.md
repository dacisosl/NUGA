## 색 (워치 · 다크)
배경 #0B0C0F · 표면 #16181D · 글자 #F4F3EF · 보조 #9A9EAA
질문 #4C7BFF · 발표 #1FA89E · 협동 #9B6BD6 · 기타 #5C606B · 경고 #FF8A3D

## 수준 배지
학생 이름표의 바탕색이 수준을 나타낸다. A: 배경 #1A1C21 흰 글자 · B: 흰 배경 + 테두리 #C9CBD2 · C: 배경 #D6D8DE. 이름표 오른쪽 위에 작은 A·B·C 배지를 얹고, 배지를 누르면 B → C → A 순으로 바뀐다. 표에는 따로 수준 열을 두지 않는다.

## 상태 칩
통과 = 파랑 연함(#E8EDFB/#2448C9) · 확인 필요 = 주황 연함(#FDEEE3/#B4470B) · 수정 권장 = 주황 진함(#B4470B 배경, 흰 글자) · 미작성 = 회색(#ECECEE/#4A4E5A)
기록 상태: pending(보완 전) = 주황 점 · confirmed = 없음 · skipped = 회색 점

## 타이포
IBM Plex Sans KR → Apple SD Gothic Neo → Malgun Gothic → sans-serif.
크기: 본문 14, 보조 12, 제목 20, 표 헤더 12(굵게, text2), 숫자는 tabular-nums.

## 크기
- PC 폭 기준 1440. 사이드바 200. 본문 패딩 32. 표 행 58, 헤더 44. 둥글기 카드 12, 칩 999, 버튼 8.
- 모바일 390×844. 터치 44 이상. 하단 탭 3개(홈·기록·설정). 번호 그리드 6열.
- 워치 450×450 원형. 버튼 최소 48. 카테고리 2×2, 번호 릴 가운데 큰 숫자 64sp.

## 원칙
1. 설명 문구 없이 구조로 이해되게. 라벨은 명사 1~2단어.
2. 한 페이지 = 한 가지 일.
3. 반 탭 · 과목 · 엑셀/JSON 버튼은 모든 페이지 같은 자리.
4. 상태 = 색 + 아이콘 + 글자. 색만으로 구분 금지.
5. 수업 중 입력은 탭 2~3번. 메모는 항상 선택.
6. 학생 이름은 PC에만.
